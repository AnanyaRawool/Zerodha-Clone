A frontend clone of the Zerodha trading platform built to practice modern web development skills and UI design concepts. This project focuses on recreating the user interface and layout of Zerodha’s platform for learning purposes.
##  Features

- Clean and responsive UI  
- Modern trading dashboard design  
- Structured layout similar to Zerodha  
- Built using HTML, CSS, and JavaScript
